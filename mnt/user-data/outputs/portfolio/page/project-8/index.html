— Problem & Goal
PROJECT OVERVIEW
01
기업 정체성을 보여주지 못하는 구식 홈페이지
2010년대 초반 그대로 멈춰있는 레이아웃. 제조 기업의 신뢰감과 친환경 가치를 전달하지 못함
02
모바일 사용자 이탈
반응형 미적용으로 모바일 고객 유입 시 정보 확인 자체가 어려운 상태
03
고객 문의 채널 부재
문의 메뉴는 있지만 실제 이메일·견적 시스템 미연동, 전화 외 접점이 끊겨있음

— 6 Key Improvements
PROBLEM & SOLUTION
01
Before · 문제 모바일 화면 미흡 반응형 미적용 — 모바일에서 PC 화면이 그대로 축소되어 정보 확인 자체가 어려운 상태
→
After · 개선 전 페이지 모바일 반응형 대응 메인·서브·제품 상세까지 모든 페이지 모바일 전용 레이아웃 신규 제작. 햄버거 메뉴·터치 인터랙션 적용
02
Before · 문제 정보 전달이 부족한 디자인 평면적인 텍스트 나열 — 핵심 정보가 묻히고 기업의 경쟁력이 시각적으로 드러나지 않음
→
After · 개선 인터랙션 기반 정보 시각화 stat-card·핵심사업 패널·풀스크린 환경 기부 섹션 등으로 중요 정보를 단계적으로 시각화. 가독성·전달력 동시 향상
03
Before · 문제 인터랙션 부족 → 체류시간 감소 정적인 페이지 — 방문 즉시 이탈하는 구조로 회사 정보·제품 라인업 노출 기회 부족
→
After · 개선 스크롤 연동 인터랙션으로 흥미 유도 히어로 슬라이더·파트너 플로우 배너·블랙 커튼 리빌·텍스트 순차 등장 등 다층 인터랙션으로 체류시간 증가
04
Before · 문제 업데이트 부족 → 회사 정보 단절 수년째 갱신되지 않은 인사말·연혁·인증 — 현재 회사 상태를 반영하지 못하는 정보 단절
→
After · 개선 클라이언트 자료 기반 정보 최신화 CEO 인사말·연혁·인증 현황·주요 파트너·오시는 길 — 클라이언트 제공 자료로 전 페이지 최신 정보 반영
05
Before · 문제 자료 탐색이 번거로운 구조 제품 정보가 분산되어 있고 다운로드 자료실 미존재 — 고객이 원하는 자료를 찾기 어려움
→
After · 개선 제품 상세 · 자료실 · 영상 섹션 신규 UPS 시리즈별 상세 페이지, 통합 자료실(규격서·카탈로그·매뉴얼), 제품 사용 영상 섹션 신규 제작 (영상 미수령 상태로 임시 숨김 처리)
06
Before · 문제 연락 채널 부재 문의 탭은 있지만 실제 이메일 발송·견적 폼이 작동하지 않아 사실상 전화로만 문의 가능한 상태
→
After · 개선 도입 상담·견적·서비스 폼 연동 완료 3종(도입 상담·견적 문의·서비스 요청) 문의 폼 신규 제작 및 이메일 연동. 즉시 답변 가능한 채널 확보

🌱 NEW
친환경 기부 풀스크린 섹션
스크롤 진입 시 블랙 커튼 리빌 효과 → 배경 이미지·텍스트 순차 등장. 수익 1% 환경단체 기부 메시지를 시네마틱하게 전달
📦 NEW
제품 상세 페이지 시스템
UPS 시리즈별 상세 페이지 — 갤러리·스펙 표·관련 자료 다운로드를 단일 템플릿으로 관리. JS 데이터 객체 기반 콘텐츠 확장 가능
📚 NEW
통합 자료실
규격서·카탈로그·매뉴얼을 모델별로 묶은 자료실. 시리즈/용량/상품군 다중 필터 + 검색
📱 NEW
전 페이지 모바일 반응형
햄버거 메뉴·아코디언·터치 슬라이더 등 모바일 전용 컴포넌트 신규 제작. 768px 기준 브레이크포인트
📨 NEW
3종 문의 폼 연동
도입 상담·견적 문의·서비스 요청 폼을 목적별로 분리 제작. 이메일 발송 시스템 연동으로 실시간 응대 채널 확보
